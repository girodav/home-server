# 🏠 home-server

Self-hosted services on TrueNAS SCALE, deployed via GitOps with [arcane](https://getarcane.app/).

## 🚀 First-time setup

**1. Run the setup script** (as root, edit variables at the top first):

```sh
bash scripts/setup-truenas.sh
```

**2. Place your WireGuard config:**

```
/mnt/fast/apps/qbittorrent/wireguard/wg0.conf
```
